# Блок B. Excel

* `nedoimka_analiz.xlsx` — книга: Power Query (C1), сводная (C2), формулы (C3), лист «Контроль» со сверкой итогов.
* `power_query/*.m` — M-код всех запросов с комментариями. Листы `*_static` в книге — результат выполнения этих запросов, сохранённый значениями; чтобы запросы обновлялись, их нужно вставить в Excel через «Пустой запрос → Расширенный редактор» и указать путь к CSV в параметре `DataFolder`.

## Что где

* **C1 Power Query:** `power_query/*.m` — код всех запросов с комментариями. Очистка: «;», UTF-8 с BOM, всё читается как текст, trim, «русские» числа, пустые суммы = 0, дедуп по `id` после нормализации, регион из ИНН, справочники, только налоговые КБК, FULL OUTER JOIN агрегатов.
* **C2 Сводная:** слева — недоимка, начислено и оплачено по ФО → региону с фильтром по периоду, сортировка по убыванию недоимки. Справа — регионы, отсортированные по недоимке (ТОП). Если нужен строго ТОП-5: в правой сводной откройте фильтр «Регион» → Фильтры по значению → Первые 10 → 5.
* **C3 Формулы:** ИНДЕКС/ПОИСКПОЗ по 7 ИНН и СУММЕСЛИМН по регионам с условием `priznak_nalog = "Y"`, рядом — сверка с `fakt`.
* **Контроль:** итоги Excel против эталона (Python и Oracle).
